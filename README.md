# 送付状メーカー

株式会社UKCorporation／株式会社空き家活用研究所の送付状と封筒の宛名を作って印刷するツールです。1つの本体（`送付状メーカー.html`）から3つの形で使えます。

| 形 | 使う人 | 印刷 | 担当者・アドレス帳・履歴の共有 |
|---|---|---|---|
| **社内Webアプリ版**（`gas/`） | 会社のGoogleアカウントを持つ全員 | ボタン1つでそのまま | 全員で共有（同時編集しても消えない） |
| 共有リンク版（claude.ai アーティファクト） | 同じClaude組織のメンバー | 印刷専用タブを開いて印刷 | 同じ組織のメンバーで共有 |
| ファイル版（`送付状メーカー.html` を開く） | 誰でも | ボタン1つでそのまま | 自分のPCの中だけ |

会社全体で使うなら **社内Webアプリ版** を使ってください。公開のしかたは `gas/導入手順.md` にあります。

## ファイル

- `送付状メーカー.html` … 本体。3つの版すべての元になるファイル。
- `gas/Code.gs` … 社内Webアプリ版のサーバー側（Google Apps Script）。起動時に GitHub の `gas/index.html` を取り込んで表示し（10分キャッシュ＋ドライブに控え）、共有データを Google ドライブ内の JSON ファイルに保存して項目ごとの更新を直列に適用します。
- `gas/appsscript.json` … Apps Script の設定（タイムゾーン、ウェブアプリの公開範囲の初期値）。
- `gas/index.html` … 社内Webアプリ版の画面。本体のコピーで、`tools/build.py` が生成します。Apps Script はこのファイルを GitHub から読み込みます。
- `gas/導入手順.md` … 社内Webアプリ版の公開手順。
- `print.html` … 共有リンク版が「印刷」で開く印刷専用ページ。`tools/build.py` が生成します。
- `tools/build.py` … 本体から `print.html`・`gas/index.html`・claude.ai 公開用ファイルを生成します。

## 角印について

角印（社印）の画像は本体に含めていません（公開リポジトリに置かないため）。各版の「差出人」→「登録内容を編集」→「社印（角印）の画像」で登録すると、その版の共有データ（社内Webアプリ版はドライブ、共有リンク版は claude.ai）に保存され、全員で使えます。

## 印刷のしくみ

- 社内Webアプリ版・ファイル版：「印刷」ボタンでそのままブラウザの印刷画面が開きます。
- 共有リンク版：claude.ai の枠内では印刷画面を開けないため、「印刷」で `print.html` を新しいタブに開きます。自動で印刷画面が出ない環境では、タブ上の案内どおり Ctrl+P（Mac は ⌘P）で印刷します。タブが開かない場合は「PDFで保存」を使います。
- 印刷画面では「余白＝なし」「ヘッダーとフッター＝オフ」「倍率100%」にしてください。

## 更新のしかた

1. `送付状メーカー.html` を編集する。
2. `python3 tools/build.py <出力先>` を実行する（`print.html`、`gas/index.html`、公開用ファイル一式が更新されます）。
3. 社内Webアプリ版：`gas/index.html` を push すれば10分以内に反映されます（再デプロイ不要）。`gas/Code.gs` を変えたときだけ Apps Script 側を更新して「新バージョン」でデプロイする。
4. 共有リンク版：出力先の `送付状メーカー.html` を本体、`print.html` を添付ファイルとしてアーティファクトに公開する。
