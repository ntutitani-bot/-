# 送付状メーカー（社内Webアプリ版）導入手順

会社の Google アカウントでログインすれば誰でも使える形で公開します。Claude のアカウントは要りません。
貼り付けるのは `Code.gs`（短いファイル）1つだけです。画面（`index.html`）は GitHub から自動で読み込むので貼り付け不要です。

## 1. プロジェクトを作って Code.gs を入れる（3分）

1. 会社の Google アカウントでログインした状態で https://script.google.com/ を開き、「新しいプロジェクト」を押す。
2. 左上の「無題のプロジェクト」を押して、名前を「送付状メーカー」にする。
3. `Code.gs` の中身をコピーする。GitHub のページ
   https://github.com/ntutitani-bot/-/blob/claude/delivery-note-maker-improve-h89eud/gas/Code.gs
   を開き、右上の「Copy raw file」（四角が2つ重なったアイコン）を押すと全文がコピーされます。
4. Apps Script の画面中央（`コード.gs`）に最初から入っている数行を消して、貼り付ける。
5. Ctrl+S（Mac は ⌘S）で保存する。

## 2. 公開する（2分）

1. 右上の「デプロイ」→「新しいデプロイ」を押す。
2. 左上の歯車（種類の選択）→「ウェブアプリ」を選ぶ。
3. 次のように設定する。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（会社名）内の全員** ← 会社の Google アカウントを持つ人だけが開けます
4. 「デプロイ」を押す。
5. 「アクセスを承認」が出たら承認する。自分のアカウントを選び、「詳細」→「送付状メーカー（安全ではないページ）に移動」→「許可」の順に進む（自作スクリプトなので必ずこの警告が出ます）。
6. 表示された「ウェブアプリのURL」（`https://script.google.com/a/macros/.../exec` の形）をコピーして、社内に配る。

## 3. 最初に開いたあと

- 最初に開いた人の画面で、差出人（UKCorporation／空き家活用研究所）と書類の候補が自動で登録されます。
- 角印は本体に入っていません（公開リポジトリに置かないため）。「差出人」→「登録内容を編集」→「社印（角印）の画像」で `社印.png` を一度登録すると、全員の送付状で使えます。
- 以前の共有リンク版（claude.ai）に登録した担当者・アドレス帳・角印をまとめて引き継ぐには、共有リンク版の下端「設定の書き出し・読み込み」→「設定を書き出す」でファイルを保存し、新しいアプリの同じ場所で「設定を読み込む」を押してそのファイルを選びます。

## しくみ

- 画面（HTML）は GitHub の `gas/index.html` を起動時に取り込んで表示します。10分間はキャッシュし、控えをドライブにも保存するので、GitHub に届かないときは控えで動きます。画面の修正は GitHub 側を直すだけで反映され、再デプロイは不要です。
- データはあなたの Google ドライブ「送付状メーカー」フォルダの `送付状メーカー_data.json` に保存されます。差出人・担当者・アドレス帳・書類候補・送付履歴を全員で共有し、誰が印刷したかも自動で残ります。
- バックアップはこの JSON ファイルをコピーするだけです。削除すると初期状態に戻ります。
- `appsscript.json` は設定の参考ファイルです（貼り付けなくても動きます）。

## うまくいかないとき

- 「このアプリは確認されていません」と出る：手順 2-5 のとおり「詳細」から進めば使えます。会社の管理者が外部アプリを制限している場合は、管理者に「社内で作成した Apps Script の実行を許可」してもらってください。
- 他の人が開くと「アクセス権が必要です」と出る：「デプロイを管理」→ 鉛筆マーク →「アクセスできるユーザー」を「（会社名）内の全員」に変更する。
- 「画面を読み込めませんでした」と出る：GitHub 側のファイルが取得できず、控えもまだ無い状態です。少し待って開き直すか、GitHub のリポジトリが公開のままか確認してください。
- 印刷画面が出ない：ブラウザがポップアップや印刷をブロックしていないか確認し、それでも出なければ Ctrl+P（Mac は ⌘P）を押してください。
